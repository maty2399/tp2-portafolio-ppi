Portafolio web del grupo de la Tecnicatura Superior en Desarrollo de Software del Instituto Superior Manuel Belgrano. Reúne los currículums de sus integrantes y los proyectos realizados para Práctica Profesionalizante.

## Proyectos

- **CVs:** currículums personales de los integrantes (`cvs/`).
- **Formulario de contacto:** formulario para consultas de Dietética Natural (`formulario/`).
- **Landing page:** presentación de Driada Dietética y Herboristería (`landing-page/`).
- **Guía de estilos:** componentes y estilos del sitio (`guia-estilos/`).
- **Catálogo TechShop:** catálogo con búsqueda, filtros y carrito (`catalogo/`).
- **Atrapa el Bug:** minijuego con niveles de dificultad (`minijuego/`).

## Cómo abrir el portafolio

1. Cloná o descargá este repositorio.
2. Abrí `index.html` en el navegador para navegar el portafolio.

Para probar el catálogo, abrí la carpeta del proyecto en Visual Studio Code e iniciá un servidor local (por ejemplo, con la extensión **Live Server**). El catálogo carga sus productos desde `productos.json` y necesita servirse por HTTP.

Algunas páginas cargan Bootstrap desde un CDN, por lo que necesitás conexión a Internet para ver esos estilos y componentes.
